# 주봉 스캐너 봇 — 설치

유튜브 요약봇과 같은 저장소·같은 텔레그램 봇을 쓴다.
새로 만들 것 없다.

---

## 1. 파일 두 개 올리기

저장소: `github.com/hokyun896kim/youtube-summary-bot`

```
scan_bot.py                        ← 저장소 루트
.github/workflows/scanner.yml      ← workflows 폴더 안
```

**`scanner.yml`은 반드시 `.github/workflows/` 폴더 안에** 있어야 한다.
그 폴더에 이미 `bot.yml`이 있을 것이다. 그 옆에 넣으면 된다.

### 올리는 법

1. 저장소 첫 화면 → `Add file` → `Upload files` → `scan_bot.py` 끌어놓기 → `Commit changes`
2. `.github` → `workflows` 폴더 클릭 → `Add file` → `Upload files` → `scanner.yml` → `Commit changes`

---

## 2. 시크릿

**이미 있다.** 유튜브 봇이 쓰는 `TELEGRAM_TOKEN`, `TELEGRAM_CHAT_ID`를 그대로 쓴다.
아무것도 안 해도 된다.

---

## 3. 첫 실행

`Actions` 탭 → **한주에한번매매 스캐너** → `Run workflow`

| 입력 | 처음엔 |
|---|---|
| 시총 상위 N | `300` ← 동작 확인용 |

3~5분 뒤 텔레그램에 오면 성공이다.
확인되면 다음부터 `0`(전 종목)으로 둔다. 전 종목은 15~20분 걸린다.

---

## 4. 자동 실행

**매주 금요일 16:00 KST.** 손댈 것 없다.

깃허브 크론은 몇 분에서 십몇 분 늦게 뜨는 일이 잦다.
금요일 저녁에 안 오면 `Actions` 탭에서 실행 기록을 확인한다.

---

## 5. 메시지 읽는 법

```
📊 [한주에한번매매 #7] 주간 스캔
2026-08-22 16:02 · 기준 주봉 2026-08-17
대상 2325종목 · 정지의심 115 배제

🔴 매수 (1건)
  · 티앤엘 (340570) 29,700원
     목표 33,264 · 손절 28650
  금요일 종가 매수 → 예약매도 목표가 지정가

🟢 신규조건 (2건)
  · 레이언스 (228850) 7,700원 / 손절선 5,610
  · 에스넷 (038680) 4,170원 / 손절선 3,665

지난 주 대비
  + 티앤엘 (340570) → 매수
  ~ 레이언스 (228850) 신규조건 → 매수
  − 038680 조건 이탈
```

| 표시 | 뜻 | 할 일 |
|---|---|---|
| 🔴 매수 | 이번 주가 첫 음봉 | 금요일 종가 매수 + 목표가 지정가 예약매도 |
| 🟡 대기 | 조건 충족, 양봉만 이어짐 | 다음 음봉 주에 매수 |
| 🟢 신규조건 | 이번 주 조건 충족 | 다음 음봉을 기다린다 |
| ⛔ 중단 | 첫 음봉이 손절선 이탈 | **진입하지 않는다** |
| ⚠자본변동? | 액면분할·병합 의심 | 공시 확인 |
| ⚠급변동 | 2년 내 주간 +150% 이상 | 확인 |

**「지난 주 대비」가 제일 중요하다.** 전체 목록을 매번 읽지 말고 변한 것만 본다.

## 6. 로그가 자동으로 쌓인다

매주 실행될 때마다 저장소의 `scan_log.csv`에 한 줄씩 누적된다.

```
스캔일, 기준주, 상태, 종목, 코드, 조건주, 주봉, 종가, 목표가, 손절선, 확인
2026-08-22, 2026-08-17, 매수, 티앤엘, 340570, 2026-08-03, 음봉, 29700, 33264, 28650,
```

**결과(팔았는지·얼마에)는 자동으로 안 채워진다.**
6개월 뒤 이 파일을 받아서 열 두 개만 채우면 자기 확률을 계산할 수 있다.

## 7. 운용 규칙 (확정)

| 항목 | 값 |
|---|---|
| 시간축 | 주봉 |
| 이평선 | 26 / 52 / 104주 |
| 진입 | 4조건 충족 후 첫 음봉의 금요일 종가 |
| 목표 | **+12% 전량청산** (러너 없음) |
| 손절 | **음봉이 직전 양봉 블록 저점을 종가상 이탈** |
| 종목당 | 계좌의 5% |
| 동시 보유 | 8종목 |

**손절과 목표 모두 금요일 종가로만 판정한다.** 장중에 스쳐도 무시한다.
(단 목표는 지정가 예약매도이므로 장중 체결된다.)

## 8. 반드시 기억할 것

**진입 신호 자체에는 랜덤 대비 통계적 우위가 확인되지 않았다.**
백테스트 성과는 전부 청산 규칙에서 나왔다.

> 목표 도달하면 판다. 손절선 깨지면 판다.
> **이 둘을 지키는 것만이 검증된 우위다.**

한 번 어기면 남는 게 없다.
